# Курсовая работа по теме "Создание API по учету производственных задач, выполняемых сотрудниками предприятия"
## Установка
Для работы с API нужно установить виртуальное окружение
```bash
python -m venv .venv
.venv/scripts/activate
```
Установить зависимости проекта 
```bash
pip install -r requirements.txt
````

## Запуск API
Для запуска API version 1.0 необходимо прописать следущую команду
```bash
uvicorn app.main:app_v1 --reload  
```
